# Claude Code subagents

Subagent definitions are Markdown files with YAML front matter (`name`, `description`, and optionally `tools` and
`model`) followed by the agent's system prompt. Claude Code loads them from `~/.claude/agents/` (all projects) or
`<project>/.claude/agents/` (one project).

Conventions: one file per agent, `<name>.md`, listed in this README. Install by copying or symlinking the
file into an agents directory.
